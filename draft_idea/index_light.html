What is openEO

One API.
Any cloud. Any language.

Whether you're using Python, R, JavaScript or QGIS — openEO lets you write your analysis once and run it on any compatible back-end. No vendor lock-in. No rewriting code.

✓
Standardised processes Use the same process names across every back-end
✓
Datacube model Work with spatiotemporal datacubes natively
✓
Open source Apache 2.0 — inspect, extend, contribute
example.py
import openeo # Connect to any openEO back-end conn = openeo.connect("openeo.cloud") conn.authenticate_oidc() # Load Sentinel-2 data as a datacube cube = conn.load_collection( "SENTINEL2_L2A", spatial_extent={"west": 4.0, "east": 4.5, "south": 51.0, "north": 51.5}, temporal_extent=["2024-06-01", "2024-08-31"], bands=["B04", "B08"] ) # Compute NDVI ndvi = cube.ndvi(nir="B08", red="B04") ndvi.download("ndvi.nc")
