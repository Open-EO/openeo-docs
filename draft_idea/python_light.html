Python Client

The openEO Python client lets you connect to any compatible back-end, process Earth observation data as datacubes, and run scalable batch jobs — all from Python.

🐍 openeo 0.31.0 · Python ≥ 3.9

Installation

Install the openEO Python client using pip or conda. We recommend using a virtual environment.

pip
pip install openeo
conda
conda install -c conda-forge openeo
💡

For optional features like GeoDataFrame support, install extras: pip install openeo[localprocessing]

Connect & Authenticate

Use openeo.connect() to connect to a back-end URL. Authentication is handled via OIDC (recommended) or Basic Auth.

connect.py
import openeo # Connect to an openEO back-end conn = openeo.connect("openeo.cloud") # Authenticate via OIDC (browser-based, recommended) conn.authenticate_oidc() # Or use device flow (for headless environments) conn.authenticate_oidc_device() # Check who you're logged in as print(conn.describe_account())

Loading Collections

Browse available collections and load a spatiotemporal subset as a DataCube.

load_collection.py
# List all available collections collections = conn.list_collections() # Load Sentinel-2 L2A with spatial & temporal filter cube = conn.load_collection( "SENTINEL2_L2A", spatial_extent={ "west": 4.0, "east": 4.5, "south": 51.0, "north": 51.5, "crs": "EPSG:4326" }, temporal_extent=["2024-06-01", "2024-08-31"], bands=["B04", "B08", "SCL"] ) print(cube) # DataCube with shape info

Applying Processes

Chain processes on your DataCube. openEO defines 200+ standardised processes you can combine into a processing graph.

NDVI — Normalized Difference Vegetation Index

ndvi.py
# Built-in shorthand ndvi = cube.ndvi(nir="B08", red="B04") # Or use band math directly b04 = cube.band("B04") b08 = cube.band("B08") ndvi = (b08 - b04) / (b08 + b04)

Cloud masking

cloud_mask.py
from openeo.processes import array_element # Use SCL band to build a cloud mask scl = cube.band("SCL") # SCL values 4 (vegetation) and 5 (non-vegetated) are clear cloud_mask = (scl == 4) | (scl == 5) # Apply mask to datacube cube_masked = cube.mask(~cloud_mask)
ℹ️

Processing graphs are lazy — nothing is computed until you call .download() or .execute_batch().

Batch Jobs

For large-scale processing, submit a batch job that runs asynchronously on the back-end.

batch_job.py
# Create and start a batch job job = ndvi.execute_batch( outputfile="ndvi_output.nc", title="NDVI Belgium summer 2024", out_format="NetCDF" ) # Monitor status job.start_and_wait() # blocks until complete # Or poll manually print(job.status()) # "queued" | "running" | "finished" # List all your jobs for j in conn.list_jobs(): print(j["id"], j["status"])

User-Defined Functions (UDFs)

When the built-in processes aren't enough, write a UDF in Python and run it server-side on the datacube.

udf_example.py
from openeo.udf import XarrayDataCube def apply_datacube(cube: XarrayDataCube, context: dict) -> XarrayDataCube: """Custom UDF: smooth NDVI with a rolling mean.""" array = cube.get_array() smoothed = array.rolling(t=3, min_periods=1).mean() return XarrayDataCube(smoothed) # Apply UDF to the datacube result = ndvi.apply(process=openeo.UDF(open("udf_example.py").read()))
⚠️

UDF availability depends on the back-end. Check conn.list_udf_runtimes() to see what's supported.
