# openEO Setup

This will include information about:

- Different ways to install and setup openEO clients
- How to connect to openEO backends
- Infer information about the backend (e.g. available data, processes, etc.)

So the processes such as:

- `openeo.connect()`
- `openeo.list_backends()`
- `openeo.describe_backend()`
- `openeo.describe_processes()`
- `openeo.describe_collection()`
- `openeo.describe_user()`
